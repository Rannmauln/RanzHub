## 1. Prerequisites

- Roblox account
- Roblox game "Grow A Garden 2"
- Script executor (KRNL, Delta, Potassium, etc.)

## 2. Installation Steps

### Step 1: Download Executor

**For PC:**
- KRNL: https://krnl.ca
- Delta: https://deltaexploits.xyz
- Synapse X: https://x.synapse.to (paid)

**For Mobile:**
- Arceus X: https://arceusx.net
- Fluxus: https://fluxus.xyz

### Step 2: Open Roblox

1. Open Roblox
2. Login to your account
3. Search "Grow A Garden 2"
4. Join the game

### Step 3: Execute Script

**Free Version:**
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Rannmauln/RanzHub/main/main_scripts/loader.lua"))()
```

**Premium Version:**
```lua
getgenv().PremiumKey = "YOUR-KEY-HERE"
loadstring(game:HttpGet("https://raw.githubusercontent.com/Rannmauln/RanzHub/main/main_scripts/loader.lua"))()
```

### Step 4: Open GUI
Press K key to open/close the GUI.

### Step 5: Toggle Features
Click ON/OFF buttons to enable/disable features.

## 3. Configuration
You can edit config/free_config.lua or config/premium_config.lua to customize settings.

Common settings:
1. WalkSpeed: Speed of movement
2. SellInterval: How often to sell fruits
3. AutoSteal: Enable/disable stealing

## 4. Troubleshooting
If script doesn't work:
1. Check executor compatibility
2. Make sure game is fully loaded
3. Try different executor
4. Check internet connection
