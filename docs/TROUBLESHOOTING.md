# 🔧 TROUBLESHOOTING

## Common Issues & Solutions

### 1. Script Not Loading

**Problem:** Script doesn't load or shows error

**Solutions:**
- Check internet connection
- Try different executor
- Make sure game is fully loaded
- Check URL is correct

### 2. "Error on Potassium"

**Problem:** Script error on Potassium executor

**Solutions:**
- Use v1.3.0 or newer (supports Potassium)
- Update Potassium to latest version
- Disable heavy features

### 3. Key Not Working

**Problem:** Premium key says invalid

**Solutions:**
- Check key format (XXXX-XXXX-XXXX-XXXX)
- Make sure key is active (not deactivated)
- Check if key expired
- Contact support for help

### 4. Webhook Not Sending

**Problem:** Discord webhook doesn't work

**Solutions:**
- Check webhook URL format
- Make sure webhook is active in Discord
- Check Discord server permissions
- Test webhook with Discord API

### 5. UI Not Showing

**Problem:** Press K but GUI doesn't appear

**Solutions:**
- Make sure script loaded successfully
- Check console for errors
- Try changing keybind in config
- Restart game and execute again

### 6. AutoSteal Not Working

**Problem:** Stealing doesn't work

**Solutions:**
- Make sure there are other players
- Check AutoSteal is enabled
- Try different steal mode
- Check if game updated
