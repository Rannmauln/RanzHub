## 📌 What is DarkFarm?

DarkFarm is an auto farm script for Roblox game "Grow A Garden 2".  
It automates planting, harvesting, selling, and more.

## 🎯 Features

### FREE Version
- ✅ Auto Harvest
- ✅ Auto Plant
- ✅ Auto Water
- ✅ Auto Sell
- ✅ Anti AFK
- ✅ Basic GUI

### PREMIUM Version
- ✅ ALL Free Features
- ✅ Auto Steal (Anti-Detect)
- ✅ Auto Pets (Hatch, Equip, Sell)
- ✅ Auto Expand
- ✅ Auto Tame Wild
- ✅ Premium GUI
- ✅ Discord Webhook
- ✅ No Watermark
- ✅ Priority Support
